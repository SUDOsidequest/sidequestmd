# The Lesion Decoder Ring

An open-source, SFL-inspired educational tool for learning to describe dermatologic lesions through structured clinical and linguistic choices.

## What it does

The Lesion Decoder Ring guides learners through morphology-first clinical description.

Rather than treating medical vocabulary as a list of jargon terms, the tool models lesion description as a network of constrained choices:

- Primary structure determines which lesion classes are available.
- Some choices are mutually exclusive.
- Some features can accumulate, such as colour and surface change.
- Some lexical systems may remain unrealized when they are not assessed, not relevant, or intentionally omitted.
- The output is a clinical morphology phrase, not a diagnosis.

## Project direction

This is the first module in a broader set of medicine-and-language learning tools.

Planned future modules may use the structured output from this tool to explore:

1. Clinical nominal-group structure and grammatical compression.
2. Patient report versus examination finding.
3. Certainty, stance, and attending voice.
4. Register, genre, and the organization of clinical notes.
5. Reverse-engineering the language choices behind clinical documentation.

## Status

Early prototype. Built as a static educational web tool.

## Clinical safety

This tool is for morphology practice and language learning only. It does not diagnose lesions, provide medical advice, replace clinical examination, or substitute for supervision, institutional documentation standards, or clinical judgment.

No patient data, clinical screenshots, or institution-specific materials belong in this repository.
