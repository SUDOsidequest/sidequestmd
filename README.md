# The Lesion Decoder Ring

An open-source, SFL-inspired educational tool for learning dermatologic lesion description through structured clinical and linguistic choices.

## Run it

This is a static site. Open `index.html` in a browser or deploy the folder to Netlify.

## Project structure

- `index.html` — interface
- `styles.css` — Art Deco / apparatus styling
- `app.js` — state, gating, guardrails, and phrase realization
- `data/lesion-systems.json` — machine-readable systems and lexical choices

## Clinical safety

Morphology-practice tool only. It does not diagnose lesions, provide medical advice, or substitute for clinical evaluation, supervision, or local documentation standards. Do not add patient data, clinical screenshots, or institution-specific material.
