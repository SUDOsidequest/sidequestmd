# sidequestmd
Open-source experiments at the intersection of medicine, language, and learning.

## Projects

- **The Lesion Decoder Ring** — an SFL-inspired teaching tool for building and examining dermatologic morphology descriptions through constrained lexical choice.

## Status

Early prototype. Educational use only; not a diagnostic tool and not a substitute for clinical judgment, supervision, or institutional documentation standards.

## Privacy and clinical safety

This repository contains no patient data, clinical screenshots, or institution-specific materials.
